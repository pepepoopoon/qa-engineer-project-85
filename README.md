## О проекте

В рамках учебного QA-проекта проводится тестирование Codebattle — онлайн-платформы для соревнований по программированию.

**Основные возможности приложения:** регистрация через GitHub, создание игр с другими пользователями и ботом, выбор сложности и языка программирования, решение задач, чат, история игр и рейтинг игроков.

**Содержимое репозитория:** тестовая документация, тест-кейсы, результаты тестирования и баг-репорты, подготовленные в ходе проекта.
